# COVY - Application de covoiturage scolaire

COVY est une application mobile qui facilite les déplacements des élèves en mettant en relation les familles et les conducteurs. Elle vise à rendre les trajets domicile-école plus accessibles, économiques et sécurisés.

## 🚀 Fonctionnalités principales
- Inscription et connexion des utilisateurs (Familles / Conducteurs)
- Création et recherche de trajets
- Mise en relation et système de réservation

## 🛠 Stack Technique
- **Langage :** Kotlin 
- **Framework :** Android SDK
- **Outils :** Gradle, Git
